# シンクローマ — キャラクター設定書

> 漫画タッチ（青春ラブコメ：エムゼロ／月曜日のたわわ／夫婦以上、恋人未満。／ギャル系）を言語化した仕様。
> 絵師・AI画像生成への発注書としても使える粒度で記述する。
> 学園名：**彩明（さいめい）学園**。舞台：放課後の旧美術準備室「シンクロ部」。

---

## 主人公 — 灯里 透（あかり とおる）
- **ポジション**：プレイヤーの分身。物静かな“陰キャ”寄りの男子。色彩感覚だけは図抜けている。
- **学年**：高校2年。
- **見た目**：黒髪のさらりとしたミディアム前髪、やや眠そうな黒目がち。標準体型。
  制服は彩明学園のブレザー（紺）を少し着崩す。
- **性格**：観察眼が鋭く口数は少ないが、芯は優しい。色＝感情を読むのが得意。
- **アートメモ**：瞳は控えめなハイライト。表情は微細（眉と口角で語る）。

## メインヒロイン — 七海 ひかり（ななみ ひかり）
- **ポジション**：ギャルヒロイン。明るく距離感が近い。物語と演出の“顔”。
- **学年**：高校2年（透と同級）。
- **見た目**：明るい栗色〜ハニーブロンドの巻きロング、毛先メッシュにシンクロマゼンタ(`#ff5d8f`)。
  大きく艶のある瞳（ハイライト多め）、頬のチーク強め、白い歯のこぼれる笑顔。
  制服はスカート短め・カーディガン肩掛け、耳に小さなピアス。スタイル良め。
- **性格**：陽キャでぐいぐい来るが、面倒見がよく涙もろい。透の色彩センスに本気で惚れている。
- **シンボルカラー**：シンクロマゼンタ `#ff5d8f`。
- **アートメモ**：たわわ系の柔らかいボディライン＋ギャルの華やかさ。瞳のハイライトは星型一点。

## サブヒロイン — 蒼井 凪（あおい なぎ）
- **ポジション**：クール才媛タイプの幼なじみ。シンクロ部の現実的なブレーキ役。
- **見た目**：黒髪ロングストレート、切れ長の瞳、眼鏡（時々外す）。制服きっちり。
- **シンボルカラー**：シンクロシアン `#43d6c4`。
- **性格**：素っ気ないがツンデレ。透を昔から見ている。

## ムードメーカー — 陽（ひなた）先輩
- **ポジション**：3年の天真爛漫な先輩。部の太陽。
- **シンボルカラー**：シンクロイエロー `#ffd94a`。
- **見た目**：ショートのオレンジ髪、八重歯、元気な大きい瞳。

# シンクローマ — アートディレクション

> 青春学園系パズルゲーム「シンクローマ（Synchroma）」のビジュアル指針。
> タイトルの由来は **Synchro（同調）× Chroma（色彩）**。光と色を“シンクロ”させて解く青春パズル。

## 1. 目指すタッチ

エムゼロ／「月曜日のたわわ」／「夫婦以上、恋人未満。」／ギャル系ラブコメ（「陰キャの僕に…ギャルがベタ惚れ」系）の
**柔らかく艶やかな青春ラブコメ漫画タッチ**。

- 線：細めでクリーン、強弱のある主線。塗りはアニメ塗り＋やわらかいグラデ。
- 瞳：大きめ・ハイライト多め・うるっとした艶。
- 肌：血色のよい頬の赤み（チーク）。やわらかいフェード。
- 全体：放課後・夕暮れ・制服・きらめき。爽やかさ＋ほんのり色気。

> ⚠️ 実装上の注意：コードで生成できるのは SVG / CSS / Canvas のベクター表現まで。
> 最終的な漫画タッチの立ち絵は**絵師またはAI画像生成**で用意し、`assets/img/` のプレースホルダ枠に差し替える。
> 本リポジトリの SVG キャラはサイズ・配置・トーン確認用の**仮ビジュアル**。

## 3. タイポグラフィ

- ロゴ／見出し：太めの明朝・ゴシック（和文）。きらめきと青春感。
- 英字ロゴ "SYNCHROMA"：トラッキング広め、グラデ＋艶ハイライト。
- 本文UI：読みやすいゴシック（system-ui / Hiragino / Noto Sans JP）。

## 4. UI演出の方針

- タイトル：夕暮れグラデ背景＋舞う花びら＋ロゴの艶めき＋脈動するスタートボタン。
- 画面遷移：色がスッと“同調”して切り替わる（クロマワイプ）。
- ボタン：押下でクロマ三色が弾けるリアクション。
- HUD：丸み・やわらかい影・クリーム地のカード。
